使用說明

上機前務必確認插對地方！

如因插錯腳座造成模組或電器損壞恕不負責。

請先透過 USB 測試連線！

請先插上 USB 電源，確認模組可成功連上家中網路及 Home Assistant 後，再安裝到電器上。

還不知道模組該插在哪裡？

請務必先確認您的冷氣/除濕機安裝位置，以免插錯。

設定步驟
  1. 開啟 Wi-Fi 熱點：

    從模組的 USB-C 孔上電後，等待約 30 秒，模組會自動建立一個 Wi-Fi 熱點。

  2. 辨識您的設備：

    根據您的電器品牌，選擇對應的 Wi-Fi 熱點名稱：

    • 國際冷氣: ac-st01-pa
    • 日立冷氣: ac-st01-ht
    • 大金冷氣: ac-st01-dk
    • 三菱電機冷氣: ac-st01-mt
    • 日立除濕機: st01-dehumidifier
    • 三菱重工壁掛: ac-st01-mhi-w
    • 三菱重工吊隱: ac-st01-mhi-c
    • 國際舊款冷氣: ac-st01-pa-v2
    • 日立舊款冷氣: ac-st01-ht-v2
    • 日立全熱交換: erv-st01-ht
  3. 連線至熱點：

    熱點連線密碼為 12345678。連上後，在瀏覽器輸入網址 192.168.4.1/wifi 進入設定頁面。

  4. 設定 Wi-Fi 連線：

    在設定頁面中，選擇您家中的 2.4GHz Wi-Fi 名稱，並輸入密碼，然後按下 SAVE。

  5. 確認設備上線：

    模組重啟後會自動連上您家中的 Wi-Fi。您可以在路由器的管理頁面看到新設備，其名稱後面會附加 MAC 位址以供辨識。

  6. 整合至 Home Assistant：

    Home Assistant (HA) 通常會自動提示發現新設備，點擊加入即可。若無自動提示，請至 HA 的「設定」>「裝置與服務」>「新增整合」，搜尋並選擇 ESPhome，然後輸入模組的 IP 位址手動加入。

  7. 關於舊款機型：

    日立、國際的舊款冷氣可能僅支援模式切換及溫度調節，若其他功能（如風速、風向）無法使用，此為正常現象。

韌體更新

韌體下載位址：

請前往 fw.siot.cc，輸入您購買時的「訂單編號」，即可下載您機型對應的韌體檔案。

韌體更新前請注意！

更新韌體後，Wi-Fi 設定有可能被清除，需重新設定連線。請務必依照步驟順序操作，避免裝置進入異常狀態。

※ 若 OTA 更新失敗或出現異常，將需要把模組拆下，並透過 USB 接上電腦重新燒錄韌體喔！

方式一：OTA 無線更新 (建議)

  1. 下載 OTA 韌體檔案：

    請前往上方的 fw.siot.cc，輸入訂單編號後，下載檔名結尾為 ota.bin 的檔案，並儲存至電腦。

  2. 開啟裝置設定頁面：

    在瀏覽器網址列輸入裝置的 IP 位址（例如 http://192.168.x.x），進入裝置設定頁面。

  3. 上傳韌體並等待更新完成：

    捲動至頁面最下方，找到 OTA Update 區塊，點擊「選擇檔案」並選取剛才下載的 ota.bin，再按下 Update。上傳完成後頁面會自動跳轉並顯示 done，代表韌體更新成功。

  4. 重新設定 Wi-Fi（若有需要）：

    若更新後裝置 Wi-Fi 設定被清除，模組將重新建立熱點。請依照上方「設定步驟」中的 Wi-Fi 連線說明，重新完成網路設定，Home Assistant 即會自動恢復連線。

方式二：USB 有線更新

  1. 下載 USB 韌體檔案：

    請前往上方的 fw.siot.cc，輸入訂單編號後，下載檔名結尾為 factory.bin 的檔案，並儲存至電腦。

  2. 連接電腦：

    將模組拆下，並使用一條支援資料傳輸的 USB 線將其連接至電腦（ Windows 或 Mac 皆可）。

  3. 透過網頁進行燒錄：

    建議使用 Chrome 或 Edge 瀏覽器，前往 https://web.esphome.io：

    • 點擊頁面上的 CONNECT 按鈕。
    • 在彈出的視窗中，選擇帶有「USB JTAG」字樣的連接埠選項。
    • 連線成功後，點擊 INSTALL。
    • 選擇剛剛下載的 factory.bin 檔案，並等待進度條跑完即完成燒錄。
  4. 重新設定設備：

    燒錄完成後請先拔除 USB 線，再重新插回電源。最後，請依照上方的「設定步驟」重新將模組連上網路並加入 Home Assistant，最後再插回電器上。
