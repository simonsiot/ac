常見問題 Q&A

整理自 LINE 客服最常被問的問題
看完後多數問題都能自己解決

三件事最常出包，先看這裡

1. 先 USB 測試

收到後務必先用 Type-C 線測試連網，確認模組沒問題後，再裝上冷氣。

2. 不要插錯腳座

接頭只防「反插」不防「插錯位置」，插錯會直接燒模組，不保固。

3. 確認版本買對

標準版需 HA、HK 版功能少、終極版可切換廠牌，先看 Q1.2 對照表。

章節 1

購買前先確認

Q1.1

我家是 OO 牌冷氣，可以用嗎？

看的是冷氣有沒有「可外接 Wi-Fi 模組」這項規格，不是看年份。各品牌對應的接頭如下：

  • 📌 日立壁掛 / 吊隱：CN10（部分新機型 CN30）
  • 📌 大金：CN-SAA
  • 📌 國際 Panasonic：CN-CNT
  • 📌 三菱電機：CN105
  • 📌 三菱重工：CNS

目前不支援：格力、禾聯、美的 (Media)、Panasonic 除濕機。

超過 10 年的舊機型多半沒有對應接頭。不確定的話，拆機殼拍接頭照片用 LINE 傳給我看，幫您確認再下單。

Q1.2

標準版 / HK 版 / 終極版，我該選哪個？

📌 30 秒快速選擇

  • 只想用 Siri / Apple 家庭 開關冷氣 → HK 版
  • 想做自動化、看耗電量、整合其他家電 → 標準版（需要 HA）
  • 多個品牌或想常換 → 終極版（一機四廠牌切換）
比較項目 HK 版 標準版 終極版
需要 HA Server ❌ 不用 ✅ 要 ✅ 要
完整功能（送風 / 除濕 / 自動） ❌ 沒有 ✅ ✅
多品牌切換 ❌ ❌ ✅ 4 牌
價格 +150 元 基本款 最高

⚠️ 常見誤解

  • • Apple TV ≠ HA Server。Apple TV 只是 HomeKit Hub，沒辦法跑 HA。
  • • 「HomeKit 直連」≠「全功能」。HK 版受 Apple 協議限制，沒有送風、除濕、自動模式。
Q1.3

不支援的品牌（格力 / 美的 / 禾聯）怎麼辦？

目前確認 不支援：
格力、禾聯、美的 (Media)。

沒有詳細研究這幾種品牌，所以不支援。

替代方案 — 改用紅外線控制：

  • • Aqara 空調伴侶（紅外線發射 + 溫濕度回報）
  • • SwitchBot 萬能遙控

⚠️ 紅外線方案無法精準回報冷氣狀態（例如「現在實際在運轉的模式」），但基本開關、溫度、模式切換都做得到。

跟原廠 / Aqara 比有什麼不同？

控制方式 直連主板 直連主板 紅外線

自動化能力 強（HA） 受限 看搭配

章節 2

安裝步驟

Q2.1

模組剛收到，第一步該做什麼？

不用先燒韌體，出貨前我已經燒好了。請務必照順序：

  1. 1. ⚡ 先用 Type-C 接電腦 / 充電器供電
    模組約 30 秒後會自動建立 Wi-Fi 熱點
  2. 2. 📱 連上模組的熱點
    密碼固定：12345678
  3. 3. 🌐 設定 Wi-Fi
    瀏覽器開 192.168.4.1/wifi，選您家 2.4GHz Wi-Fi、輸入密碼、按 SAVE
  4. 4. ✅ 確認加入 HA / HomeKit 並能正常控制
    至少先確認「看得到裝置 + 開關有反應」
  5. 5. 🔌 都正常後，才把模組接到冷氣

千萬不要省略前 4 步直接插冷氣！萬一冷氣腳座有問題或接錯位置，會直接燒掉模組，事後無法挽回。

💡 Type-C 只是「設定 / 燒錄用」，裝上冷氣後就不需要 Type-C 了，模組會由冷氣主板供電。

Q2.2

該插冷氣的哪個接頭？

🔴 重要警示

接頭有防呆，只防「反插」，不防「插到錯的位置」！冷氣板上會有很多 4-pin / 5-pin 接頭，插錯會直接燒毀模組，不在保固範圍。

各品牌應該找的接頭：

  • 🔌 三菱電機：紅色 / 白色 5-pin，標示 CN105（面對主機右下角）
  • 🔌 三菱重工：5-pin，標示 CNS
  • 🔌 日立壁掛：黑色 4-pin CN10（部分新機 CN30）
  • 🔌 日立吊隱：同 CN10 系列，位置不同（拆殼找「黑色那一顆」）
  • 🔌 大金：標示 CN-SAA
  • 🔌 國際 Panasonic：標示 CN-CNT

不確定時的標準動作：拆殼後拍主機板照片 → LINE 傳給我 → 我幫您圈出正確接頭再裝。花 5 分鐘確認，勝過燒一個模組。

章節 3

HA 整合

Q3.1

加進 HA 後看不到資訊 / 按了沒反應？

請依序排查：

  1. 1. 到 HA 整合頁面，按 get info 按鈕，看會不會讀到冷氣型號 / 資訊
  2. 2. 沒讀到 → 按 restart 重啟模組
  3. 3. 還是沒有 → 拔下來檢查 有沒有插到正確接頭（很可能是位置插錯）
  4. 4. 接頭也對 → 可能是冷氣型號太新或太舊，拍冷氣型號貼紙給我，必要時寄回換新

💡 日立、國際的舊款可能只支援開關 + 溫度，沒有風速 / 風向是正常的，不是壞掉。

Q3.2

怎麼從 HA 接到 HomeKit / Siri？

標準做法（3 步驟）：

  1. 1. HA → 設定 → 裝置與服務 → 新增整合，搜尋 HomeKit Bridge 並安裝
  2. 2. 設定時會出現實體勾選清單 — 只勾 climate.冷氣名稱 這一個
  3. 3. 其他溫度 / 濕度 / 耗電量 sensor → 不要勾，留在 HA 用就好

❓ 為什麼 HomeKit 出現一堆怪選項？

就是因為剛剛勾太多了！模組會丟出很多 sensor，全部勾起來 Apple 家庭就會塞滿奇怪的開關。只留 climate.xxx 就乾淨了。

章節 4

連線 / 使用狀況

Q4.1

模組常常斷線 / 變 unavailable，怎麼辦？

最快的判斷方式：USB 單獨測試 24 小時

  1. 1. 拔下模組，單獨用 USB 供電放著（不要插冷氣）
  2. 2. 觀察 24 小時，看會不會斷
  3. 3. 看結果：

❌ USB 供電也斷

模組瑕疵或您所在地 Wi-Fi 訊號太弱 → 寄回換新（見 Q5.2）。

✅ USB 很穩定

代表是冷氣裡訊號太差 → 請水電拉長線把模組拉出機殼。

💊 自己做過 OTA 後變不穩？

  • • 一般情況「能用就不要動」，OTA 不需要主動做
  • • 已經做了變不穩 → 把錯誤訊息丟 AI 問，或重燒回我提供的 bin
  • • 自己改 YAML 改壞了 → 把自己加的部分刪掉
Q4.2

模組上的藍燈是什麼意思？
LED燈狀態 意義 該擔心嗎？
● 慢閃（USB 測試時） 正在找 Wi-Fi ✅ 正常，等它連上
● 先慢閃後不亮 已連上 Wi-Fi ✅ 正常
○ 完全不亮（插冷氣後） 沒有供電 ❌ 不正常
檢查腳座是否插錯
章節 5

出貨 / 售後

Q5.1

多久會出貨？怎麼追蹤？
  • 📦 通常下單後幾天內出貨。缺料時我會主動 LINE 通知您。
  • 📬 出貨後約三天，到貨後全家會發訊息通知您取貨。
  • 💬 寄出後可在好賣家查詢目前進度。
Q5.2

收到後不能用 / 想退換貨，怎麼處理？

標準流程（不用付任何運費）：

  1. 1. 💬 先 LINE 告知狀況
    型號不支援 / 模組壞掉 / 想換版本，任一狀況都先講
  2. 2. 📦 包好寄到任一全家
    請在機器上憑「寄件編號＋末三碼」列印單據貼在外包裝，運費我這邊付
  3. 3. 🔍 我收到後測試
    • • 模組瑕疵 → 換新給您，取貨付 100 元，我會把 100 元放在包裹內（等於免費）
    • • 型號不支援 → 全額退款
    • • 買錯版本 → 補差 / 退差換新版本

⚠️ 例外：因「插錯接頭」造成的燒毀不在保固範圍。這就是為什麼章節 2 一直強調要先 USB 測試 + 拍照確認接頭。

進階

給想研究的人

ℹ️ 一般買家完全不需要看這區。出貨已預燒完成，照前面 5 章操作就能用。以下適合想自己客製化、改 YAML、升級韌體的進階使用者。

A.1

怎麼自己重燒韌體？

一般用不到。只有要更新到新版功能 / 修 bug 時才需要重燒。

方式 1：USB 線燒（最穩）

  1. 1. 到 GitHub 下載 bin 檔：TaiSEIA_ESPhome_samples
  2. 2. 模組接電腦 Type-C
  3. 3. 開 ESPhome 線上燒錄頁面 → Connect → 選 USB Single Serial → INSTALL → 選 bin
  4. 4. 燒完要 重新設定 Wi-Fi（連模組熱點 → 輸入家中 Wi-Fi）

方式 2：OTA 線上燒（不用拆）

  1. 1. 到 HA 找出模組的 IP 位址
  2. 2. 瀏覽器連上該 IP，捲到最下方「OTA update」
  3. 3. 上傳 ota.bin → 等顯示「OTA 完成」即可
A.2

怎麼自己改 YAML？
  1. 1. 先確認模組可正常控制冷氣再開始改
  2. 2. 參考範例：Climate-ESP32C3.yaml
  3. 3. 常見可改項目：devicename、upper_devicename、移除不要的 sensor
  4. 4. 改完用 OTA 上傳新韌體
  5. 5. 萬一改壞 → 把自己加的刪掉，或重燒原始 bin

⚠️ 重要聲明：自行修改 YAML 不在售後支援範圍。改完不穩、無法控制需自己排查（可丟 ChatGPT 或社群問）。重燒回原廠 bin 永遠是有效的還原方式。

A.3

怎麼把耗電量加到 HA 能源頁？

HA → 設定 → 儀表板 → 能源 → 個別裝置 → 新增裝置，選擇冷氣的「耗電量」sensor 即可。

💡 加進去後才開始累積資料，加之前的舊資料不會回填。
